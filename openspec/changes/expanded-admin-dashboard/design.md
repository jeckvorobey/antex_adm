## Context

Оператору нужно за несколько секунд увидеть очередь внимания, сегодняшнюю активность, обороты и актуальные курсы. Экран должен оставаться плотным, но не превращать каждое число в отдельную карточку.

## Goals / Non-Goals

**Goals:**

- Сохранить Quasar/Material язык и текущую светлую тему.
- Сделать очередь внимания первым смысловым блоком.
- Объединить пользователей и заявки в одну поверхность `Сегодня`.
- Сохранить двухколоночную структуру `Пользователи / Заявки` на мобильном.
- Не смешивать денежные суммы с операционными счётчиками.
- Сделать desktop-компоновку самостоятельной, а не растянутой мобильной.

**Non-Goals:**

- Добавлять графики или декоративные иллюстрации.
- Менять глобальную навигацию.
- Создавать новую страницу заявки.

## Decisions

1. Верх desktop: `Требуют внимания` и `Сегодня`; низ: `Оборот` и `Курсы`.
2. Mobile: блоки идут вертикально, но внутренняя структура `Сегодня` остаётся двухколоночной.
3. Используются единые белые поверхности, лёгкие разделители и минимальная тень; вложенных карточек нет.
4. Красный цвет используется только для просрочки, жёлтый — для новых заявок, синий — для заявок в работе.
5. Строка внимания ведёт в существующий раздел заявок; отдельный дублирующий detail flow не создаётся.
6. Desktop dashboard не задаёт собственный `max-width` и заполняет доступный контейнер страницы.
7. Значения первого ряда `Сегодня` центрируются относительно своих ячеек на desktop и mobile.
8. Оборот использует различимые валютные маркеры и усиленный вес числовых значений.
9. Курсы сохраняют двухколоночную таблицу из оригиналов: валюты и их флаги стоят по краям строки, итоговый курс показан в центре, а базовая цена снизу сокращена до `БЦ`.
10. Флаги отображаются без цветного фона; USDT использует зелёный token-маркер с символом `₮`, а код правой валюты стоит перед её флагом.

## Risks / Trade-offs

- Две колонки на очень узких экранах требуют коротких подписей и компактной типографики.
- Длинные значения курса могут переполнять строку; они ограничиваются одной строкой, а сетка на мобильном становится одноколоночной.

## Verification

- Unit tests: данные, очередь, валюты, курсы, refresh и error state.
- `npm run lint`, targeted Vitest и production `npm run build`.
- Ручная визуальная проверка mobile и desktop при доступном browser preview.
