# Спецификация состояний admin dashboard

## Purpose
Описывает доступные состояния и навигацию операционного dashboard в admin panel.

## Requirements

### Requirement: Dashboard сохраняет состояния и навигацию

Admin SHALL сохранять доступные состояния загрузки, ошибки, пустых данных, ручного обновления и переходов к заявкам и курсам.

#### Scenario: Summary не загрузился

- **WHEN** запрос `/api/admin/summary` завершается ошибкой
- **THEN** dashboard показывает контролируемое сообщение и действие повторной загрузки
