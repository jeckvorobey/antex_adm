# Спецификация операционного admin dashboard

## Purpose
Описывает структуру и визуальные требования адаптивной операционной сводки admin panel.

## Requirements

### Requirement: Dashboard собирает операционные данные в одном экране

Admin SHALL показывать очередь внимания, сегодняшнюю активность, обороты и курсы в одной адаптивной сводке.

#### Scenario: Оператор открывает dashboard на desktop

- **WHEN** ширина viewport соответствует desktop
- **THEN** dashboard занимает всю доступную ширину контейнера и показывает верхнюю и нижнюю двухколоночные сетки

#### Scenario: Оператор открывает dashboard на mobile

- **WHEN** ширина viewport соответствует mobile
- **THEN** основные поверхности идут вертикально без горизонтального переполнения

### Requirement: Операционные значения следуют утверждённым оригиналам

Admin SHALL центрировать значения первого ряда `Сегодня`, показывать различимые валютные маркеры и усиленные суммы оборота, а курсы отображать двухколоночной таблицей с итоговым курсом и базовой ценой.

#### Scenario: Отображение курсов

- **WHEN** summary содержит валютные пары
- **THEN** каждая строка курса показывает маркеры валют пары, итоговый курс сверху и подпись `Базовая цена` со значением снизу
