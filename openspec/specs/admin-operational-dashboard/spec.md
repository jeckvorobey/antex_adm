# Спецификация операционного admin dashboard

## Purpose

Описывает структуру и визуальные требования адаптивной операционной сводки admin panel.

## Requirements

### Requirement: Dashboard собирает операционные данные в одном экране

Admin SHALL показывать очередь внимания, сегодняшнюю активность, обороты и курсы в одной адаптивной сводке.

#### Scenario: Оператор открывает dashboard на desktop

- **WHEN** ширина viewport соответствует desktop
- **THEN** dashboard занимает всю доступную ширину контейнера и показывает верхнюю и нижнюю двухколоночные сетки

#### Scenario: Оператор открывает dashboard на mobile

- **WHEN** ширина viewport соответствует mobile
- **THEN** основные поверхности идут вертикально без горизонтального переполнения

### Requirement: Операционные значения следуют утверждённым оригиналам

Admin SHALL центрировать значения первого ряда `Сегодня`, показывать различимые валютные маркеры и усиленные суммы оборота, а курсы отображать двухколоночной таблицей с итоговым курсом и подписью `БЦ`.

Для `USDT` SHALL использоваться asset `src/assets/images/Usdt-icon.svg`, для `ATXG` —
`src/assets/images/atxg.svg`, а для `RUB`, `THB`, `GEL`, `VND` — флаги `🇷🇺`, `🇹🇭`,
`🇬🇪`, `🇻🇳`. В блоке оборота маркеры SHALL иметь размер `32px × 32px`, в блоке
курсов — `25px × 25px`. Маркеры SHALL отображаться без дополнительных фонов,
border, border-radius и box-shadow.

#### Scenario: Отображение курсов

- **WHEN** summary содержит валютные пары
- **THEN** каждая строка курса показывает маркер первой валюты перед `1 <КОД>`, маркер второй валюты после второго кода, итоговый курс в формате `1 GEL от 31.27 RUB` и подпись `БЦ` со значением базовой цены снизу
- **AND** маркеры имеют размер `25px × 25px` и не имеют дополнительных фона, border, border-radius или box-shadow

#### Scenario: Отображение оборота

- **WHEN** summary содержит строки оборота по валютам
- **THEN** перед кодом валюты показывается соответствующий SVG или флаг
- **AND** маркер имеет размер `32px × 32px` без дополнительных фона, border, border-radius или box-shadow
